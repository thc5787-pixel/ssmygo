# ssmygo P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the P0 ssmygo: a single-exe Windows tray Shadowsocks client (MyGo native UI, shadowsocks-go core) that reads the original `gui-config.json`, proxies through legacy AEAD / SS2022 servers on one local mixed port, and sets the system proxy in Disabled / PAC(rules) / Global modes.

**Architecture:** Layered: `internal/ui` (MyGo, main thread) → `internal/controller` (state, transactions) → `config` / `core` / `sysproxy` / `rules`. Only `ui` and `cmd` import MyGo. shadowsocks-go is vendored under `third_party/` with two patches (A: protocol registry, B: Manager Start/Stop); ssmygo's own protocols (`mixed`, legacy AEAD) live in `internal/core/*` and register through patch A.

**Tech Stack:** Go 1.27.3, MyGo v0.7.4 (`github.com/egoist/mygo`), shadowsocks-go `65ba171` (vendored), `golang.org/x/crypto`, `golang.org/x/sys/windows`, `google.golang.org/protobuf/encoding/protowire`.

**Spec:** `docs/superpowers/specs/2026-11-01-ssmygo-design.md` (also read `docs/requirements.md` and `docs/spike-findings.md`).

## Review Focus

1. **Real-world `ss://` text** — links pasted with CRLF, surrounding spaces, URL-encoded / Chinese `#remarks`, base64 with or without padding, uppercase method names: all parse; garbage lines are reported, not fatal. → tests in Task 4.
2. **Damaged or unusual `gui-config.json`** — `index` out of range, empty `configs`, unknown method string from a newer client, BOM at file start: app starts, index clamped, unknown method server kept but marked invalid. → tests in Task 3.
3. **Port change to a busy port** — user sets proxy port to one already in use and presses OK: error shown, previous port keeps working, config on disk unchanged. → test in Task 10.
4. **User's prior proxy restored exactly** — a corporate PAC URL / custom proxy + bypass existing before first enable is restored byte-for-byte on Disable, on Quit, and on next start after a crash. → tests in Task 10.
5. **Half-closed TCP** — client sends request then closes its write side (curl `--http1.0`-style); response must still arrive through legacy AEAD and mixed inbound. → tests in Tasks 5 and 6.
