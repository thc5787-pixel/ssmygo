# ssmygo P1-E Implementation Plan: server strategies and global hotkeys

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Load Balance / High Availability strategies over shadowsocks-go client groups, and six global hotkeys with the original Hotkeys window.

**Architecture:** `core.Build` emits one client per member plus a `clientGroups` entry named `proxy`; `internal/hotkey` converts the original WPF hotkey strings to MyGo accelerators; the controller gains strategy and hotkey-action operations; `ui` adds menu items, the Hotkeys window and registration through `mygo.GlobalShortcut`.

**Tech Stack:** Go 1.27.3, no cgo, MyGo v0.7.4, vendored shadowsocks-go `clientgroup`. Branch `feat/e-conveniences` from `feat/c-sources`.

**Spec:** `docs/superpowers/specs/2026-11-02-ssmygo-e-conveniences-design.md`
