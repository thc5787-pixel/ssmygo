# ssmygo P1-C 设计：在线配置（SIP008）、分享服务器、扫描屏幕二维码

> 日期：2026-11-02　状态：用户已在对话中逐节确认（§1–§3），要求直接开始
> 上级文档：[`requirements.md`](../../requirements.md)（M4、M5、M6、U8、U9，§4.5 ⑤⑥，R6）
> 范围：P1 子项目 C。

## 1. 已确认的决定

| # | 决定 | 来源 |
|---|---|---|
| C-D1 | 订阅获取：有可用服务器时经 ssmygo 本地端口（HTTP 代理）获取；没有可用服务器（无服务器、插件未运行）时直连。同一次获取失败不改走直连重试 | 用户选择 |
| C-D2 | 扫码得到 `http(s)://` 链接时，询问"添加为在线配置（SIP008）订阅？"并显示链接；同意后添加并立即更新。不打开浏览器 | 用户选择 |
| C-D3 | 启动后在后台更新全部订阅；只有失败时通知。选中的服务器保持选中 | 用户选择（与原版相同） |
| C-D4 | 订阅来的服务器在"编辑服务器"窗口中只读，并标注"来自订阅 <主机>"。原版可以编辑但下次更新会被覆盖 | 用户确认 |
| C-D5 | QR 用纯 Go 库：生成 `github.com/skip2/go-qrcode`（MIT），识别 `github.com/makiuchi-d/gozxing`（Apache-2.0）；截屏用 GDI（`x/sys/windows`，无 cgo） | 方案 A |
| C-D6 | 订阅 URL 常带密钥：界面完整显示，日志只记录主机名 | 设计 |

## 2. 组件

```
config/sip008.go   解析 SIP008：官方格式，以及原版的宽松搜索（JSON 任意位置含
                   server、server_port、password、method 的对象）
config             Config.OnlineConfigSource []string（json "onlineConfigSource"，原版字段）
subscribe/         Fetch(ctx, url, proxyPort) ([]Server, Result)：HTTP GET；proxyPort>0 时
                   经 http://127.0.0.1:<port>；超时 15 s；响应 ≤ 1 MB；≤ 1000 台服务器
controller         AddSubscription(url) / RemoveSubscription(url) / UpdateSubscription(url) /
                   UpdateAllSubscriptions()；启动后后台 UpdateAll
qrcode/            Encode(text, size) []byte（PNG，黑白，含静区）；Decode(image.Image) []string
screencap/         CaptureAll() ([]image.Image, error)：每个显示器一张，按物理像素（DPI 感知）
ui                 在线配置窗口、分享服务器配置窗口、托盘菜单项、扫码流程、编辑服务器只读行
```

### 2.1 更新订阅

- 取得服务器后，把 `group` 设为订阅 URL，替换所有 `group == url` 的服务器。
- 订阅服务器排在自己的服务器之后（原版 `SortByOnlineConfig`：`group` 为空的在前，其余按出现顺序）。
- 保持选中：按（地址、端口、加密方式、密码、插件）匹配原来选中的服务器。找不到时选同一订阅的第一台，再找不到选第一台，并通知。
- 获取失败、响应不是 JSON、超过 1 MB、没有服务器：都算失败，该订阅原有服务器保留（空响应不会清空订阅）。
- 无效条目（端口不对、不支持的加密方式）跳过并计数；超过 1000 台只取前 1000 台。
- 本次运行内记录每个订阅的结果：服务器数、跳过数、错误。
- 订阅服务器用了插件时，第一次运行插件仍要经过 A1 的信任对话框。

### 2.2 扫描屏幕二维码

- 截取所有显示器，逐张识别全部二维码。
- 得到 `ss://` 链接：全部经现有 `ImportURLs` 导入（与剪贴板导入相同的校验），然后打开"编辑服务器"窗口。
- 得到 `http(s)://` 链接（且没有 `ss://`）：按 C-D2 询问；有多个时只取第一个。
- 其他内容："二维码内容无效：…"（能解析出密码时把密码遮住）。
- 没有找到："未找到二维码。请放大二维码或把它移到屏幕中央。"（原版文案）
- 截屏失败："截屏失败：…"，并记日志。

## 3. 窗口（沿用原版布局，按 MyGo 设计文档优化）

### 3.1 在线配置（480×510）

```
┌ 在线配置 ───────────────────────────────────────┐
│ ┌ 订阅列表 ────────────────────────┐ [更新]     │
│ │ https://sub.example.com/a  ✓ 12  │ [全部更新] │
│ │ https://x.example/b        ⚠     │ [复制链接] │
│ │                                  │ [移除]     │
│ └──────────────────────────────────┘            │
│ URL [_________________________________] [添加]  │
└─────────────────────────────────────────────────┘
```

- 行：URL；本次运行更新过的显示"✓ 12"（服务器数）或"⚠"（鼠标悬停显示原因：HTTP 404、超时、响应中没有服务器……）。
- 更新、全部更新在后台运行，运行时按钮不可用，窗口不卡。完成后刷新行状态；"编辑服务器"窗口若开着，同步新的服务器列表。
- 复制链接：复制选中的 URL。
- 移除：窗口内确认"移除这个订阅及其 12 台服务器？"，确认后删除。
- 添加：必须是 `http://` 或 `https://` 且不重复，错误显示在输入框下方；合法则添加并立即更新。

### 3.2 分享服务器配置（660×400）

```
┌ 分享服务器配置 ─────────────────────────────────────────┐
│ ┌──────────────────────┐ ┌──────────────────────────┐  │
│ │       二维码          │ │ 服务器列表（同托盘标题）   │  │
│ └──────────────────────┘ └──────────────────────────┘  │
│ [ss://…（只读）                                   ] [复制] │
└─────────────────────────────────────────────────────────┘
```

- 左右两栏各占一半；打开时选中当前服务器。
- 二维码随选择更新；深浅色主题下都是白底黑码加静区，方便手机识别。
- 链接用 `config.FormatURL`（SIP002，含插件），只读，带"复制"按钮。

### 3.3 托盘菜单

- 服务器 ▸ … 编辑服务器… / **分享服务器配置…** / **扫描屏幕二维码…** / 从剪贴板导入 URL…
- **在线配置…** 放在"前置代理…"后面（原版顺序）。

### 3.4 编辑服务器窗口（C-D4）

- `group` 非空的服务器：字段只读，行内标注"来自订阅 <主机>"；不能删除、复制，可以选中和上下移动无效（订阅服务器始终排在后面）。
- 订阅更新时，窗口中自己服务器的未保存修改保留，订阅服务器部分换成新的。

## 4. 错误处理

| 情况 | 结果 |
|---|---|
| 获取失败（DNS、超时、TLS、HTTP 状态不是 200） | 该订阅保留原有服务器；行显示"⚠ 原因"；全部更新时汇总为一条通知"M 个订阅中有 N 个更新失败" |
| 响应超过 1 MB、不是 JSON、没有服务器 | 按失败处理，保留原有服务器 |
| 条目无效 | 跳过并计数（"添加 12 台，跳过 2 台"） |
| 超过 1000 台 | 取前 1000 台，其余计为跳过 |
| 经代理获取时服务器断开 | 本次失败并说明，不改走直连；下次重新选择路径 |
| 选中的服务器被更新删除 | 按 §2.1 选择替代并通知 |
| 截屏失败 | "截屏失败：…"，记日志 |
| 屏幕上有多个二维码 | 按 §2.2 |

## 5. 测试

| 层 | 测试 |
|---|---|
| sip008 | 官方格式；原版宽松搜索（嵌套对象、数组）；插件字段；无效条目跳过；1000 台上限 |
| subscribe | `httptest`：200、404、超时、超过 1 MB、不是 JSON、空列表；经本地代理（进程内 core 计数到请求）；无可用服务器时直连；日志只有主机名 |
| controller | 只替换该订阅的服务器；保持选中及替代规则；订阅服务器排在后面；失败保留旧服务器；启动更新不阻塞 `Start` |
| qrcode | `ss://` 往返（含长的 SS2022 链接、插件链接）；把二维码画进大图后按 100%、150%、200% 缩放仍能识别 |
| screencap | 截取主显示器，尺寸正确且不是全黑；没有交互桌面时跳过 |
| ui（无头） | 两个窗口浅色、深色快照；添加校验；更新中按钮不可用；移除确认；分享窗口的二维码能解回显示的链接；编辑服务器中订阅行只读 |
| 人工验收 | 真实订阅（有服务器、无服务器两种情况）；4K/150% 显示器上扫码；手机扫分享窗口的二维码；`docs/acceptance-c.md` |

## 6. 不做

- 定时自动更新（只在启动时更新）
- SIP008 的流量、到期信息显示（`bytes_used` 等）
- 扫描摄像头或图片文件中的二维码
